# TechPortfolio - Gabriel Paiva

Bem-vindo ao repositório do meu portfólio profissional.  
Este projeto é uma **Single Page Application (SPA)** moderna, responsiva e interativa, desenvolvida para apresentar minha trajetória, habilidades e projetos como **Desenvolvedor Full Stack**.

🔗 **Acesse online:**  
[https://gabrdsp.github.io/TechPortfolio/](https://gabrdsp.github.io/TechPortfolio/)

---

## 🚀 Tecnologias Utilizadas

O projeto foi construído utilizando uma stack moderna, focada em performance e experiência do desenvolvedor:

- **React.js** – Biblioteca principal para construção da interface.
- **Vite** – Build tool de próxima geração, garantindo um ambiente de desenvolvimento extremamente rápido.
- **Tailwind CSS** – Framework CSS utilitário para estilização rápida, responsiva e customizável.
- **Lucide React** – Coleção de ícones leves e consistentes.
- **GitHub Pages** – Hospedagem estática e deploy automatizado via `gh-pages`.

---

## ✨ Funcionalidades Principais

- **Design Responsivo & Clean**  
  Layout adaptável para mobile, tablet e desktop, com estética profissional (tons de azul e cinza).

- **Carrossel 3D Interativo (Coverflow)**  
  Seção de **“Projetos em Destaque”** com navegação estilo *drag-to-scroll*, onde o item central ganha destaque e os laterais sofrem escala e desfoque.

- **Navegação Fluida**  
  Links de âncora com rolagem suave (*smooth scroll*) entre as seções.

- **Modais Dinâmicos**
  - **Detalhes do Projeto:** exibe informações aprofundadas, tecnologias e links ao clicar em um projeto.
  - **Avaliação:** formulário interativo para coleta de feedback de clientes/parceiros.

- **Animações Suaves**  
  Uso de transições CSS e keyframes para entrada de elementos (*Fade In*, *Slide Up*).
